# SIEM Projects and Security Investigations

## Overview

Welcome to my SIEM Projects repository.

This directory contains practical Security Information and Event Management (SIEM) projects focused on security monitoring, threat detection, log analysis, threat hunting and incident investigation.

The objective is to demonstrate practical SOC Analyst skills through hands-on security investigations, detection queries, alert analysis and documented security scenarios.
