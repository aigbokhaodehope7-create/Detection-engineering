# Splunk SPL Detection Queries

## Overview

This directory contains practical Splunk Search Processing Language (SPL) queries for security monitoring, threat hunting and SOC investigations.

## Query Categories

1. Authentication and Failed Logins
2. Brute Force Detection
3. Password Spraying Detection
4. PowerShell Execution Monitoring
5. Suspicious Process Execution
6. Privilege Escalation
7. User Account Creation
8. Persistence Detection
9. Malware Investigation
10. Network Threat Hunting
11. Lateral Movement Detection
12. Windows Event Log Analysis

## Documentation

Each query will include:

- Query name and objective
- SPL query
- Explanation of the query
- Relevant Windows or Linux Event IDs
- Expected results
- False-positive considerations
- Investigation steps
- MITRE ATT&CK mapping
