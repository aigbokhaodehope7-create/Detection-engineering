# Detection-engineering
Detection Engineering Portfolio

A Practical Cybersecurity Detection Engineering Repository

Welcome to my Detection Engineering repository. This project documents my practical journey into cybersecurity, focusing on security monitoring, threat detection, incident investigation, and defensive security operations.

The repository contains hands-on projects, detection rules, investigation procedures, configuration guides, and technical documentation designed to demonstrate practical SOC Analyst skills.

My goal is to develop and document detection capabilities that help organisations identify suspicious activities, investigate potential threats, and improve their security posture.

---

About This Repository

This repository serves as a central collection of my cybersecurity projects and practical exercises.

It focuses on:

- Security Operations Centre (SOC) operations.
- Security Information and Event Management (SIEM).
- Endpoint detection and monitoring.
- Malware detection and analysis.
- Network security monitoring.
- Threat intelligence and IOC investigation.
- Incident response and threat hunting.
- Detection engineering and automation.

Tools and Technologies

The projects in this repository may use:

- SIEM: Wazuh, Splunk
- Endpoint Monitoring: Sysmon, Windows Event Viewer
- Detection Engineering: YARA, Sigma
- Network Security: Suricata, Wireshark
- Threat Intelligence: VirusTotal, AbuseIPDB, URLScan.io
- Operating Systems: Windows, Ubuntu Linux, Kali Linux
- Frameworks: MITRE ATT&CK, NIST Cybersecurity Framework

How Each Project Is Documented

Where applicable, each project includes:

1. Overview: What the project is about.
2. Objective: The security problem being addressed.
3. Tools Required: Software and technologies used.
4. Installation and Configuration: Step-by-step setup instructions.
5. Detection Logic: How the detection works.
6. Testing: How to reproduce the activity safely.
7. Results and Evidence: Screenshots, logs and detection outputs.
8. Investigation: How a SOC analyst should interpret the results.
9. Mitigation: Recommended defensive actions.
10. References: Relevant technical documentation and resources.

Learning Objectives

Through these projects, I aim to demonstrate the ability to:

- Analyse Windows and Linux security events.
- Identify suspicious processes and network connections.
- Develop and test detection rules.
- Investigate alerts using SIEM platforms.
- Enrich and investigate indicators of compromise (IOCs).
- Map suspicious activities to MITRE ATT&CK techniques.
- Document security incidents and recommend mitigations.
- Build repeatable detection and investigation workflows.

Safe Testing and Disclaimer

All activities documented in this repository are intended for educational and defensive cybersecurity purposes.

Testing is performed in controlled laboratory environments or other explicitly authorised systems.

Detection rules and scripts should be validated in a safe environment before being deployed in production.

No confidential organisational data, credentials, API keys or sensitive personal information should be published in this repository.
